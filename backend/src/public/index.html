⚡ REST API Endpoint Sketches (PDF Spec Verification)

POST /auth/register - Create account & select role
POST /auth/login - Authenticate and get JWT token
GET /students/me - Get current student profile & aggregated XP
POST /submissions - Create submission & queue AI evaluation
GET /submissions/{id} - Get submission, analysis jobs, and skills
POST /submissions/{id}/analyze - Trigger AI re-analysis version
GET /students/me/skills - Get student skill profile breakdown
GET /students/me/badges - Get unlocked badges
GET /portfolio/{username} - Shareable public portfolio view
GET /employers/candidates?skill=... - Search candidates by skill points
POST /submissions/{id}/review - Request manual human review
